# Аудиофайлы зикров

Плеер (`AudioPlayerWidget` + пакет `audioplayers`) уже полностью работает
в коде — ему просто нужны сами mp3-файлы, которые я не могу ни
сгенерировать, ни скачать в этой песочнице (нет доступа в интернет,
и создавать аудио с нуля я не умею).

## Что нужно сделать

Положите сюда mp3-файлы со следующими именами (они уже прописаны
в `lib/data/zikr_data.dart`):

```
assets/audio/morning_1.mp3
assets/audio/morning_2.mp3
assets/audio/morning_3.mp3
assets/audio/morning_4.mp3
assets/audio/evening_1.mp3
assets/audio/evening_2.mp3
assets/audio/evening_3.mp3
assets/audio/evening_4.mp3
```

Если добавите новую дуа с другим именем файла — впишите путь в поле
`audioAsset` соответствующего `DuaModel` в `zikr_data.dart`
(или в собственную дуа через редактор — сейчас для "своих" дуа аудио
из редактора не проставляется, но поле `audioAsset` в модели уже готово
для этого на будущее).

## Где взять сами аудио

- Начитать самостоятельно (диктофон + любой аудиоредактор для нарезки).
- Использовать записи, на которые у вас есть права/лицензия на
  распространение внутри приложения (многие сайты с чтением Корана и
  азкаров требуют указания источника или прямого разрешения на
  коммерческое/публичное использование — уточняйте условия лицензии).

Если файла не будет — приложение не упадёт: плеер покажет
сообщение "Аудио недоступно" вместо ошибки.
