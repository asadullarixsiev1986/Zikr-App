# Zikr App

## Быстрый старт

```bash
flutter create zikr_app_tmp        # если проекта ещё нет вообще
# затем скопируйте lib/, pubspec.yaml, assets/ из этого архива поверх
flutter pub get
flutter run
```

Если проект `zikr_app` у вас уже существует — просто замените
`lib/`, `pubspec.yaml` и добавьте папку `assets/` этими файлами,
затем `flutter pub get`.

## Новое в этой версии

- **29 утренних + 26 вечерних зикров** взяты с zikr.islom.uz —
  арабский текст, транслитерация, перевод смысла и аудио (стримится
  напрямую по ссылке, файлы не встроены в приложение). Первые 4
  вечерних (Аят аль-Курси, Ихлас, Фаляк, Наас) совпадают с утренними —
  так и должно быть, эти суры читаются оба раза. Подробности и важное
  предупреждение про язык/лицензию — см. раздел ниже.

- **Своя иконка приложения** — заменена на вашу картинку (отпечаток +
  чётки на бирюзовом фоне), лежит в `assets/icon/icon.png`.
- **Мультиязычность (RU / UZ / EN)** — переключатель в Настройках →
  "Язык". Собственный лёгкий движок локализации без кодогенерации
  (`lib/l10n/app_strings.dart`), поэтому `flutter gen-l10n` не нужен —
  просто `flutter pub get` и `flutter run`.
- Настраиваемая цель счётчика (33 / 99 / своё число) — иконка флажка
  в AppBar тасбиха или раздел "Цель счётчика" в настройках.
- Раздел **"Свои дуа"** — вкладка в экране "Дуа", кнопка "+" внизу
  справа. Хранится локально на устройстве (SharedPreferences).
- Тема **день/ночь/авто** — экран "Настройки" → "Оформление".
- Расширенная библиотека азкаров (утро/вечер) — см. предупреждение
  ниже про точность текстов.
- Реальный аудио-плеер (пакет `audioplayers`) — но сами mp3-файлы
  нужно добавить самостоятельно, см. `assets/audio/README.md`.
- Экран **"Кибла"** — определяет направление на Каабу через геолокацию
  и компас устройства.

## Запуск в VS Code

1. Установите расширения **Flutter** и **Dart** в VS Code (Extensions →
   поиск "Flutter" — расширение Dart подтянется автоматически).
2. Откройте папку `zikr_app` в VS Code: `File → Open Folder...`.
3. Откройте встроенный терминал (`` Ctrl+` ``) и выполните:
   ```bash
   flutter pub get
   ```
4. Внизу справа в VS Code выберите устройство (эмулятор Android/iOS
   или физическое устройство по USB с включённой отладкой).
5. Нажмите `F5` (или "Run and Debug" → "Run without Debugging") —
   VS Code запустит `flutter run` автоматически.

Если устройства не видно — выполните `flutter devices` в терминале,
чтобы проверить, что оно определяется на уровне самого Flutter/adb.

## Обязательные шаги для геолокации и компаса (Кибла)

Пакеты `geolocator` и `flutter_compass` не заработают без разрешений
в нативных проектах — добавьте их вручную (я не могу отредактировать
`android/` и `ios/` в этой песочнице, там нужен реальный `flutter create`).

### Android — `android/app/src/main/AndroidManifest.xml`

Добавьте внутрь тега `<manifest>`, перед `<application>`:

```xml
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
```

### iOS — `ios/Runner/Info.plist`

Добавьте внутрь `<dict>`:

```xml
<key>NSLocationWhenInUseUsageDescription</key>
<string>Приложению нужна геолокация, чтобы определить направление на Каабу (Кибла)</string>
```

## Иконка приложения

Иконка уже лежит в `assets/icon/icon.png` (ваша картинка с отпечатком
пальца и чётками), конфиг для `flutter_launcher_icons` уже прописан
в `pubspec.yaml`. Чтобы применить иконку к Android/iOS проектам:

```bash
flutter pub get
dart run flutter_launcher_icons
```

Небольшой нюанс: картинка уже нарисована как готовая карточка
(со своими скруглёнными углами, тенью и белым полем вокруг). Для
обычной иконки (Android < 8, iOS) это выглядит отлично. Для
**адаптивной** иконки Android (8+) система накладывает свою маску
(круг/сквиркл) поверх изображения — она может слегка обрезать края
чёток или оставить по краям белую кайму. Если после установки иконка
на некоторых лаунчерах будет выглядеть не идеально — решение: попросите
прислать/сделать версию без белого фона и без уже скруглённых углов
(просто отпечаток+чётки на прозрачном или сплошном фоне, с отступами
по краям) и укажите её в `adaptive_icon_foreground` в `pubspec.yaml`.

## Данные утренних зикров с zikr.islom.uz

**Важно про язык:** сайт zikr.islom.uz даёт текст на **узбекском языке**
(кириллица), а не на русском. Я сохранил перевод/значение ("Маъноси")
как есть, без своего вольного перевода на русский — так безопаснее
для точности религиозного текста. Если нужен русский перевод — надо
либо найти русскоязычный источник этих же азкаров, либо переводить
осознанно и с проверкой (я могу помочь, но такой перевод стоит
сверить с человеком, разбирающимся в теме).

**Транслитерация на латиницу** (`translitLatin`) сгенерирована
автоматически по стандартной таблице узб. кириллица→латиница.
Механическая конвертация, не носитель языка — рекомендую выборочно
сверить перед публикацией, особенно места с апострофами (ъ/ь/ў/ғ).

**Аудио — стримится, не встроено.** `audioUrl` в `zikr_data.dart`
указывает прямо на `https://zikr.islom.uz/audio/d_*.mp3` — плеер
скачивает и проигрывает на лету, файлы не лежат в вашем APK. Значит:
нужен интернет на телефоне пользователя, и в `AndroidManifest.xml`
должно быть разрешение `android.permission.INTERNET` (оно почти
всегда уже есть по умолчанию в шаблоне `flutter create`, но стоит
проверить).

**Про лицензию — важно перед публикацией.** Тексты (перевод/сборка
хадисов) и аудиозаписи на zikr.islom.uz — это редакционная работа
конкретного сайта. Сам классический текст Корана/хадисов не защищён
авторским правом, но конкретный перевод и подборка вполне могут быть.
Для личного использования/тестирования — без проблем. Если планируете
публиковать приложение в Google Play/App Store — напишите на сайт
islom.uz и уточните, можно ли использовать их контент таким образом
(многие подобные сайты разрешают некоммерческое использование со
ссылкой на источник, но лучше получить явное подтверждение).

## Известные ограничения (честно, чтобы не было сюрпризов)

- Аудио зикров — заглушка без файлов, см. `assets/audio/README.md`.
- Тексты азкаров стоит сверить с надёжным источником перед публикацией —
  см. комментарий в начале `lib/data/zikr_data.dart`.
- Код не прогонялся через `flutter analyze`/компилятор (в этой среде нет
  Flutter SDK и нет доступа в интернет для `pub get`) — проверено вручную,
  но при первом запуске возможны мелкие правки под конкретную версию SDK.
